# CLAUDE.md

Toute la documentation de reprise du projet est dans **[AGENTS.md](./AGENTS.md)**.

Lire `AGENTS.md` en entier, puis `docs/journal-de-bord.md`, avant toute modification.

Points non négociables :

- On avance **par étapes validées** par le propriétaire. Proposer, attendre l'accord, avancer d'un pas.
- **Frontend minimal** tant que la passe de design n'est pas explicitement lancée. Priorité : « ça fonctionne et c'est testable ».
- Les décisions déjà prises sont listées dans `AGENTS.md` §3 — ne pas les rouvrir sans raison.
- Tout changement (code, config, décision) → une entrée dans `docs/journal-de-bord.md`.
